# 流水账 — 个人时间管理 + AI 记录助手

> 四象限管优先级、AI 自然语言记录时间、质量分析回顾
> 开发文件：`server.js` + `index.html`
> 数据存储：服务端落盘到 `data/users/<uid>/`（JSON 文件）
> 本地端口：5202

## 四个 Tab

| Tab | 名称 | 做什么 |
|-----|------|--------|
| 事·时 | 主工作区 | 三栏布局：左栏四象限+待办、中栏环形图+时间线、右栏 AI 对话 |
| My Day | 日历与日记 | 日历选择、原始日记编辑、AI 日记生成、当日数据面板 |
| 洞察 | 分析报告 | 周报总结本周原始日记 + 月/季/半年/年 AI 时间分析 |
| 阿药 | 关于 | API key 配置、产品介绍 |

## 技术栈

- 前端：纯 HTML/CSS/JS，单文件 `index.html`
- 后端：Node.js + Express，`server.js`
- AI：DeepSeek API（用户自配 key，加密存储）
- 认证：JWT（bcrypt 密码哈希）
- 数据：服务端 JSON 文件落盘，按用户隔离

## 数据存储

```
data/users/<uid>/
├── profile.json           ← 用户信息 + 加密后的 API key
├── tasks.json             ← 四象限任务（tasks + done）
├── diary.json             ← 手写日记 { "YYYY-MM-DD": "日记文字" }
├── weekly_reports.json    ← 周报 { "周一日期": {work, life, generatedAt} }
├── YYYY-MM-DD.json        ← 每天一个文件 {date, records[], chat[]}
```

- `records`：时间记录数组，每条含 id/start/end/title/category/dimension/energy/flow/linkedTaskId
- `chat`：当天 AI 对话历史（user + assistant）
- 日记、周报不再存 localStorage，走后端 `diary.json` / `weekly_reports.json`（旧数据首次登录自动迁移）

## 数据流全景

```
用户语音输入（AI 对话）
  → POST /api/chat → DeepSeek 解析
    → 创建/修改时间记录（records）
    → 提取待办 → 创建四象限任务（tasks）
    → AI 回复文字（reply）

任务计时器
  → 停止计时 → 创建时间记录（linkedTaskId = 任务 id）
    → AI 补全 category/energy/flow

AI 日记（My Day tab）
  → 加载聊天历史 → DeepSeek 生成日记体文本

周期洞察
  → 加载多天 records → DeepSeek 分析趋势
```

## API 路由

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/api/auth/register` | 注册 |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/auth/me` | 获取当前用户信息 |
| PUT | `/api/auth/apikey` | 设置/更新 API key |
| DELETE | `/api/auth/apikey` | 删除 API key |
| GET | `/api/day/:date` | 读取某天数据 |
| POST | `/api/day/:date` | 写入某天数据 |
| GET | `/api/day-range` | 读取多天数据 |
| GET/POST | `/api/tasks` | 读写四象限任务 |
| GET/POST | `/api/diary` | 手写日记读写（批量） |
| POST | `/api/diary/:date` | 写某天日记（空文本 = 删除该天） |
| GET/POST | `/api/weekly-reports` | 周报读写（批量） |
| POST | `/api/weekly-reports/:monday` | 写某周周报 |
| POST | `/api/chat` | AI 对话（核心） |
| POST | `/api/ai/raw` | 通用 AI 代理（分析/日记） |
| POST | `/api/migrate` | 旧 localStorage → 服务端迁移 |

## 身份认证

- 用户注册时密码经 bcrypt 哈希存储
- 登录后返回 JWT token（30 天有效期）
- 所有 `/api/*` 请求（除 auth 外）需在 Authorization header 带 Bearer token
- API key 经 AES-256-CBC 加密后存入 profile.json
