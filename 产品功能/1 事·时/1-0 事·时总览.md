# 事·时 — 主工作区总览

## 一、功能说明

事·时是流水账的核心工作区，三栏布局：

```
┌──────────────┬────────────────────────┬──────────────┐
│   左栏 30%   │      中栏 40%          │   右栏 30%   │
│              │                        │              │
│  ┌────────┐  │  ┌──────────────────┐  │  ┌────────┐  │
│  │ 四象限  │  │  │  环形图          │  │  │        │  │
│  │ Q1  Q2 │  │  │                  │  │  │  AI    │  │
│  │ Q3  Q4 │  │  └──────────────────┘  │  │  对话   │  │
│  └────────┘  │                        │  │        │  │
│              │  ┌──────────────────┐  │  │        │  │
│  ┌────────┐  │  │  时间线列表       │  │  │        │  │
│  │ 待办   │  │  │  · 08:00-09:15   │  │  │        │  │
│  │ · 任务1 │  │  │  · 09:15-10:00   │  │  │        │  │
│  │ · 任务2 │  │  │  · 10:00-12:06   │  │  │        │  │
│  └────────┘  │  └──────────────────┘  │  └────────┘  │
└──────────────┴────────────────────────┴──────────────┘
```

**左栏**：四象限任务管理 + 今日待办列表。任务可拖拽入象限，可启动计时器。
**中栏**：日期导航 + 环形图（维度分布）+ 时间线列表。
**右栏**：AI 对话输入框 + 对话历史。语音式输入，AI 自动解析为时间记录。

## 三、三栏数据流

```
右栏 AI 对话
  → 用户输入语音式文本
    → POST /api/chat
      → AI 解析为时间记录 → 写入 records[]
      → AI 提到待办事项 → createTask action → 写入 tasks[] 四象限
    → 中栏时间线刷新

左栏任务计时器
  → 点击任务 ▶
    → 开始计时（前端 tracking）
  → 点击任务 ⏹
    → 创建时间记录（linkedTaskId = 任务 id）
    → AI 补全 category/energy/flow
  → 中栏时间线刷新

中栏手动添加
  → + 添加记录 → 弹窗 → 创建时间记录
  → 时间线内编辑 → 直接改 start/end/title
  → 时间线删除 → 确认 → 删除记录
```

## 四、共享状态

中栏的日期（`currentDate`）是全局主日期，左栏和右栏都以此为基准：
- 左栏：四象限 + 待办是全局的（不按日期），但计时器创建记录时用 `currentDate`
- 右栏：AI 对话以 `currentDate` 为默认日期创建记录
- 日期导航按钮（◀ 今天 ▶）切换 `currentDate`，中栏时间线和环形图同步刷新
