# 时间质量评估

## 一、功能说明

时间质量评估是对每条时间记录打能量分（energy）和专注分（flow）的系统。做两件事：

1. **为记录评分**：每条非睡眠记录可打 energy（-3 到 +3）和 flow（-3 到 +3）
2. **环形图展示**：当天所有记录按维度/分类聚合，在环形图中展示时间分配

energy = 这件事让你回血还是掉血
flow = 做这件事时你投入还是不投入

## 二、技术原理

### Energy/Flow 评分体系

两个维度，各 7 级：

```
副级 × 主级 = 分值

energy:
  掉血(-) / 持平(0) / 回血(+)
  × 轻微(1) / 中度(2) / 非常(3)

flow:
  不投入(-) / 一般(0) / 投入(+)
  × 轻微(1) / 一般(2) / 非常(3)
```

分值计算（`qValFromLabels`）：
```javascript
signMap × absMap = 最终分值
// 回血 + 中度 = +1 × 2 = +2
// 不投入 + 非常 = -1 × 3 = -3
```

### 评分来源

两种方式触发评分：

**1. 计时器停止 → AI 自动评分**

```
任务计时器停止
  → createRecord(linkedTaskId = 任务id)
  → tryCallAIForComplete(record, taskName)
    → POST /api/ai/raw
      → AI 根据任务名和时间段补全 category/energy/flow
    → updateRecord(energy, flow)
    → 记录打上 _eTouched=true, _fTouched=true
```

AI 评分只执行一次，在计时器停止时触发。手动添加的记录不会自动触发 AI 评分。

**2. 手动评分**

在时间线上点击 ♥️ 或 🎯 图标 → 弹出二级下拉菜单 → 选主级 + 副级 → 更新分值 → `_eTouched`/`_fTouched` 标记为 true。

分值 0 时 `_eTouched`/`_fTouched` 仍为 false（未评分状态），UI 不显示文字标签。

### 环形图渲染

```
renderMidCol(dateStr)
  → computeRingData(records)
    → 按六大维度聚合 duration
    → 按 category 聚合 duration（用于图例）
    → 按 breakdown 聚合各维度下的子活动（用于详情区）
  → 绘制 Canvas 环形图（ringCanvas）
  → 渲染图例（ringLegend）
  → 渲染六维度详情（ringDetail）
```

环形图只显示分类聚合（工作/生活-身体/生活-精神/成长），六维度详情展开在环形图下方的详情区。

### 六维度详情合并

详情区展示每个维度下的子活动和时长。同名或高度相似的活动会自动合并（字符集重叠 ≥ 阈值）。

合并规则：两个活动名共享的中文/字母/数字字符数 ≥ max(2, 较短集合大小 × 0.5) → 合并，取名字较长的保留。

### 睡眠记录特殊处理

睡眠记录（`dimension === 'sleep'`）不在质量分评估范围内：
- 时间线上不显示 ♥️/🎯 图标
- 环形图中不占扇区
- 质量分始终为 0

## 五、修改注意事项

1. **分值范围不变**：-3 到 +3，七级。改分值范围会影响 AI 补充评分的逻辑（AI prompt 中写了评分规则）和历史数据。

2. **_eTouched/_fTouched 的作用**：这两个字段标记用户/系统是否已经评过分。值为 0 且 untouched → UI 不显示文字（只显示图标）。如果删掉这个判断，所有 0 分的记录都会显示"持平"或"一般"。

3. **环形图 Canvas 尺寸固定**：120×120px。改大小需要同步调整 `computeRingData` 中的圆心和半径参数。

4. **维度合并逻辑的影响**：`mergeActs` 合并阈值改了会影响六维度详情区的展示——同维度下多个相似活动是被合并还是分开显示。

5. **AI 评分只用 `/api/ai/raw`**：这是通用轻量接口（temperature 0.7, max_tokens 2000），不和主 AI 对话共享上下文。改评分逻辑时不要切到 `/api/chat`——上下文太长、token 浪费。

6. **睡眠不做评估不是 bug**：`isSleepRecord(r)` 返回 true 时跳过质量分 UI，这是设计行为。不要让 AI 给睡觉打 energy 分。
