# 周期洞察报告

## 一、功能说明

周期洞察是第三个 tab。选择一个时间范围，AI 读取该范围内的所有时间记录，生成分析报告。

支持五种时间范围：
- 周报（最近 7 天）
- 月报（最近 30 天）
- 季报（最近 90 天）
- 半年报（最近 180 天）
- 年报（最近 365 天）

## 二、技术原理

### 报告生成流程

```
用户点击报告类型按钮
  → getPeriodRange(type)
    → 计算 from/to 日期范围
  → GET /api/day-range?from=...&to=...
    → 后端扫描 data/users/<uid>/ 目录
    → 读取范围内所有 day JSON 文件
    → 返回 { records: [...所有记录] }
  → 按日期分组 + 统计汇总
    → 总天数、总时间、按维度汇总
  → POST /api/ai/raw
    → 传入结构化数据 + 报告要求 prompt
  → AI 返回 300-500 字报告
    → 显示在页面
```

### 日期范围计算

```javascript
function getPeriodRange(type) {
  const to = todayStr();
  const d = new Date();
  if (type === 'week') d.setDate(d.getDate() - 7);
  else if (type === 'month') d.setMonth(d.getMonth() - 1);
  else if (type === 'quarter') d.setMonth(d.getMonth() - 3);
  else if (type === 'halfyear') d.setMonth(d.getMonth() - 6);
  else if (type === 'year') d.setFullYear(d.getFullYear() - 1);
  return { from: formatDate(d), to };
}
```

### 后端多天数据读取

`GET /api/day-range?from=YYYY-MM-DD&to=YYYY-MM-DD`
→ 扫描 `data/users/<uid>/` 目录下所有 `.json` 文件
→ 过滤 `from ≤ date ≤ to` 的日期
→ 读取每个文件，提取 `records` 数组合并返回

### AI 报告结构

Prompt 要求 AI 生成包含以下内容的报告：
1. 整体概览：节奏如何，主要时间花在哪里
2. 工作分析：效率和质量趋势
3. 生活分析：作息规律、精力管理
4. 成长分析：学习投入、技能积累
5. 建议：下一步可优化的点

## 五、修改注意事项

1. **day-range 接口是顺序扫描**：后端遍历 `data/users/<uid>/` 目录下所有 JSON 文件。文件数量大时（如一年 365 个文件）性能可接受。如果有性能问题，考虑按月份归档。

2. **报告长度限制为 300-500 字**：prompt 中限制了字数。如果觉得不够详细，可以调大 max_tokens。

3. **AI 报告无缓存**：每次点击都重新调 AI。如果需要缓存，可以在前端加 `reportCache[type]` 或在后端存报告。

4. **getPeriodRange 只传 from/to**：报告的时间切片逻辑在前端做，后端只负责读数据。如果未来要加自定义日期范围，只需改前端的 from/to 计算。
