# 分析日志提示词

> 用于 My Day 右侧面板。输入时间数据 + 日记原文 → 综合分析。

## 完整提示词

```
基于以下数据，生成一段综合分析。

## 时间数据
{{timeData}}

## 用户日记
{{diary}}

请从以下角度分析：
- 时间分配与质量分布
- 日记感受 vs 数据事实的交叉验证
- 这一天的整体质量判断
- 温和的改善建议

分析：
```

## 注入变量

| 占位符 | 说明 |
|--------|------|
| `{{timeData}}` | 当天完整时间数据（6维度时长、质量分布等） |
| `{{diary}}` | 用户当天日记原文 |
